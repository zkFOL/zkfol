# Paper directory

This directory contains the supplied paper PDF for the FOL-Zinc development bundle.

Files:

- `fol-zinc.pdf`: the supplied PDF version of *Integer SNARKs for First-Order Logic*. This is the authoritative paper file included with the bundle.
- `fol-zinc.pdf.sha256`: SHA-256 checksum for the included PDF.
- `fol-zinc-text-extracted.md`: text extracted for quick search and orientation.

The paper explains the FOL-to-Zinc route: FOL predicates are transformed through enriched polynomials and `mkQ_x^F`, evaluated with `beta_F` on range-checked witness data, then used as inputs for Zinc-compatible algebraic indexed relations.
